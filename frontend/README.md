# NextRole — Frontend

React + TypeScript app built with Vite. See the [project README](../README.md) for the full
picture (architecture, backend, how to run everything together).

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check and build for production
- `npm test` — run the Vitest + React Testing Library suite
- `npm run lint` — run Oxlint
